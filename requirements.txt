# Dependencies for the R.O.A.D. Barbados handwriting pipeline.
#
#     pip install -r requirements.txt
#
# PyTorch is deliberately absent. The correct wheel depends on the CUDA version of
# the machine, so installing it from here would either pull a CPU-only build or fight
# the one a GPU pod already ships with. Every rented pod and every Colab/Kaggle image
# has torch preinstalled; if yours does not, install it first from the index that
# matches your driver (https://pytorch.org/get-started/locally/). torch >= 2.4 is
# what the rest of these pins were tested against.
#
# These are the same pins the notebook installs in Section 1, and build/selftest.py
# fails if the two lists ever drift apart.

# --- model stack -------------------------------------------------------------
